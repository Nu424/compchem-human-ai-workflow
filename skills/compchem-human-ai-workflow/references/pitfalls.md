# 既知の落とし穴

条件を決めるとき、確認カードの警告を書くときに照らし合わせる。各項目は「何が起きるか → どう確かめるか / どう避けるか」。数値は目安で、系や条件によって変わる。

## エネルギー差の一貫性

- **反応式の全項で条件を揃える。** 汎関数、PAW ポテンシャル、ENCUT、PREC、vdW 補正の有無が項ごとに違うと、差をとっても誤差が打ち消されない → 実効パラメータの表で全項を並べて確認する。
- **どのエネルギーを使うかを揃える。** ASE の VASP calculator では `energy` が σ→0 に外挿した値、`free_energy` が電子エントロピーを含む TOTEN。混ぜない。
- **電子エネルギー差は、エンタルピーや自由エネルギーではない。** ZPE・熱補正・エントロピーを含まない値を、実験の生成エンタルピーや解離エネルギー D₀ と直接比べない。比べるなら、その差を注記する。
- **収束は、絶対値ではなくエネルギー差で確かめる。** ENCUT や k 点を変えたときに、求めたい差がどれだけ動くかを見る。

## 孤立原子・気相分子

- **孤立原子のスピン状態と軌道占有。** 開殻の原子は ISPIN=2 と正しい多重度（O・C は三重項、H は二重項など）が必要。立方体の箱では縮退した p・d 軌道に電子が分数占有され、基底状態より高いエネルギーになることがある → 非立方体の箱（例：15×16×17 Å）で対称性を破る、ISYM=0、SIGMA を小さく、OUTCAR の占有数で整数占有になったか確認する。
- **O₂ は三重項。** 非スピン分極で計算すると大きく不安定になる。さらに PBE は O₂ の結合を過大評価することが知られており、O₂ を参照にした生成エネルギー・酸化物の形成エネルギーに系統誤差が乗る → 注記する。補正が必要なら、補正方法を計画に書く。
- **箱の大きさ。** 真空が足りないと周期像どうしが相互作用する。極性分子では、箱を大きくするか、分子用の双極子補正（IDIPOL=4）を検討する。
- **気相分子の k 点は Γ 点だけでよい**が、箱を変えたら ENCUT と同様に収束を確かめる。

## 固体・表面

- **格子定数は、同じ汎関数で最適化した値を使う。** 実験値を使うとスラブに歪みが入る → バルクの状態方程式から決める。決めていない場合は「未検証」と注記する。
- **セル緩和（ISIF=3）は Pulay 応力に注意。** ENCUT を ENMAX の 1.3 倍程度以上にして行う。
- **非対称なスラブには双極子補正。** 片面吸着などで上下が非対称だと、周期境界をまたいで人工的な電場が生じる → LDIPOL=.TRUE.、IDIPOL=3。DIPOL はスラブの中心に置く。
- **スラブの k 点は真空方向に 1。** 面内の k 点はスラブの大きさに応じて収束を確かめる。金属は絶縁体より密な k 点が必要。
- **金属のスメアリング。** SIGMA が小さすぎると k 点の収束が遅い。σ→0 外挿エネルギーを使い、SIGMA と k 点を一緒に確かめる。
- **d・f 電子の系では LMAXMIX。** d 電子の系は 4、f 電子の系は 6。電荷密度を読み込む計算や SCF の収束に効く。
- **vdW 補正。** PBE は graphite の層間や物理吸着をほとんど結合させない → 必要なら D3 などを使い、反応式の全項に同じ補正を入れる。
- **吸着サイトの移動。** 緩和中に吸着種が別のサイトへ移ることがある → 最終構造でサイトを確認する。
- **固定層。** 下層を固定した層数と、固定層が動いていないことを確認する。

## 磁性

- **MAGMOM は初期値であって結果ではない。** 計算後の磁化（OUTCAR、`calc.results["magmom"]`）を確認する。
- **NUPDOWN は磁化を固定する拘束。** 外すと別のスピン状態に収束することがある。複数のスピン状態がありうる系では、候補を比べる。
- **Fe・Co・Ni などの磁性金属はスピン分極が必要。** 非スピン分極では別物になる。
- **明示した ISPIN が優先される。** 共通条件で ISPIN=1 を明示していると、初期磁気モーメントを設定しても非スピン分極のまま計算されうる → 開殻の系では系ごとに ISPIN=2 を明示する。

## 収束判定

- **終了コード 0 は収束ではない。** VASP は NSW や NELM に達しても正常終了する → 全 SCF ループ（VASP 6 なら OUTCAR の `aborting loop because EDIFF is reached`）と、最終の残留力を確認する。
- **緩和中の SCF 未収束は見逃しやすい。** 途中のイオンステップで NELM に達しても、緩和は続く → すべてのループを確認する。
- **EDIFFG は負の値で力の判定**（eV/Å）。正の値はエネルギー変化での判定になる。固定原子の力を除いて最大残留力を計算する。
- **対称性が構造を縛る。** ISYM で対称性を使うと、対称な鞍点に留まることがある → 吸着系・分子では ISYM=0 にするか、初期構造を少し崩す。

## ASE

- **ASE の VASP calculator は原子を元素順に並べ替える。** POSCAR・CONTCAR の順番は元の Atoms と違う（対応は `ase-sort.dat`）。CONTCAR から再開するときは並べ替えを戻す。最終構造は calculator 経由で取り出すのが安全。
- **緩和後、渡した Atoms の座標は最終構造に更新される**（VASP 内部で緩和した場合）。元の構造が必要なら先にコピーする。
- **FixAtoms は POSCAR の selective dynamics になる。** それ以外の拘束（結合長の固定など）は VASP 内部の緩和では効かない。
- **`vasp.out` は VASP の終了後にまとめて書かれる**（ASE 3.26 は標準出力をためてから書く）。計算中の進み具合は OSZICAR と OUTCAR で見る。
- **`molecule()` などが返す原子の順番を前提にしない。** 元素記号で探してから index を使う。

## Slurm

- **bash はフォアグラウンドのコマンドの実行中は trap を処理しない。** 終了予告で後始末したいときは、`&` でバックグラウンドにして `wait` する（`templates/job.slurm`）。
- **`--signal=B:TERM@120` はバッチの bash にだけ送られる。** 子プロセスへは自分で転送するか、bash 自身が STOPCAR を書く。
- **STOPCAR の LSTOP はイオンステップの区切りで効く。** 1 点計算の SCF の途中では止まらない。時間内に止まる保証もない。
- **`mpiexec python ...` にしない。** Python が MPI の数だけ起動し、同じファイルに書き込む。Python は 1 プロセスで、VASP だけを MPI で起動する。
- **MPI の各プロセスがスレッドを立てるとコアを奪い合う** → `OMP_NUM_THREADS=1`。
- **`afterok` の依存は、1 本でも失敗すると永遠に満たされない。** 集計ジョブには `afterany` を使い、集計側で失敗を除外する。
- **VASP をビルドした MPI・コンパイラと、実行時のモジュールを揃える。**
- **キューの時間上限を確認する。** 低優先度キューは上限が短いことが多い。

## MLIP

- **学習データの範囲外では信用できない。** 汎用モデルは、学習データにない元素の組み合わせ・構造・高エネルギー状態で誤差が大きくなる → 代表的な数点を DFT で確かめる計画を入れる。
- **学習データの近似を引き継ぐ。** PBE のデータで学習したモデルは、PBE の誤差傾向も引き継ぐ。ポテンシャル面を全体に柔らかく見積もる傾向が報告されているモデルもある。
- **エネルギーは同じモデルの中でだけ比べる。** 異なるモデルや DFT のエネルギーと混ぜて差をとらない。
- **モデルの名前と版を必ず記録する。** 同じ名前でも版が変わると結果が変わる。
- **緩和や振動には倍精度（float64）を使う。** 単精度では力の収束判定が不安定になることがある。
- **孤立原子・気相分子・スピン状態は苦手なことが多い。** 参照エネルギーに使う前に確かめる。
- **ase.db への同時書き込み。** ネットワーク上のファイルシステムで多数のジョブから同じ SQLite に書くと、ロックが不安定になりうる → ジョブごとに別の db か JSON に書き、集計で 1 つにまとめる。
